Place landscape images for the event gallery here.

Recommended image ratio: 16:9 (landscape). Example sizes: 1600x900, 1280x720.

Suggested filenames (you can use any names but ensure they are referenced from the app or rebuild after adding):
- fest1.jpg
- fest2.jpg
- fest3.jpg

To add images:
1. Put JPG/PNG images into `assets/images/`.
2. Ensure `pubspec.yaml` contains the `assets/images/` entry (already added).
3. Run `flutter pub get` then `flutter run` to see the gallery update.
